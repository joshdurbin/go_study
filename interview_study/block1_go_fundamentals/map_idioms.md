PROBLEM: Map Idioms — Word Frequency Counter
=============================================
Write a function that takes a string of space-separated words and returns
a map of word -> count. Then write a second function that returns the most
frequent word (break ties by lexicographic order).

This exercises:
  - Map initialization and write safety
  - Comma-ok idiom
  - Iterating maps deterministically

Example:
  Input:  "the cat sat on the mat the cat"
  Freq:   map[cat:2 mat:1 on:1 sat:1 the:3]
  Top:    "the"
